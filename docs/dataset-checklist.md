# Dataset field checklist

Before analyzing a public dataset, record:

- Publisher, source URL, retrieval date, and license.
- Geographic coverage, time range, units, and row granularity.
- Missing-value markers, duplicate rules, and known collection gaps.
- Transformations, exclusions, and the reason for each choice.

Keep raw downloads unchanged. Save derived tables separately and document the
command that produced them. Do not commit personal or sensitive records.

## Chart review

Label units and time ranges. Start bar-chart axes at zero. Explain missing data,
avoid implying causation from correlation, and link back to the source.
